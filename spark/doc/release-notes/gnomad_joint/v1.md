## [1.0] - 2026-08-05

### Added

- Initial contract. The `normalized_gnomad_joint` dataset family, narrowed to MAJOR 1, is published
  to table `gnomad_joint_v1`, one row per VCF record, from the gnomAD release named by the
  `--version` launch argument.
- Implemented against gnomAD **v4.1**, more precisely we use the joint dataset, with exomes, genomes and joint metrics.
- Locus columns `chromosome`, `start`, `end`, `reference`, `alternate`.
- Frequencies for the **joint** callset — `ac_joint`, `af_joint`, `an_joint`, `hom_joint` — covering
  the 730,947 exomes and 76,215 genomes together.
- Frequencies for the **genomes** callset alone — `ac_genomes`, `af_genomes`, `an_genomes`,
  `hom_genomes`.
- Frequencies for the **exomes** callset alone — `ac_exomes`, `af_exomes`, `an_exomes`, `hom_exomes`.
- `hom_*` columns are the source `nhomalt_*` INFO fields, renamed.

### Removed

- The gnomAD joint VCF carries close to 300 INFO fields — per genetic ancestry group, per sex, and
  filtering allele frequencies. Only the twelve global frequency columns above are published.
- `qual` and `name` are not published: gnomAD sites VCFs carry `.` in the QUAL and ID columns, so
  both would be null on every row.
