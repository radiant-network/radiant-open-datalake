## 1.0 — initial contract

First declared MAJOR. Table shape is defined by
[`Clinvar.scala`](../../../src/main/scala/org/radiant/opendatalake/normalized/Clinvar.scala), which is
the schema source of truth for this lineage: locus columns (`chromosome`, `start`, `end`,
`reference`, `alternate`, `name`), the ClinVar INFO fields lowercased and unescaped, `clin_sig` /
`clin_sig_conflict` / `clnrevstat` split into arrays, `interpretations` collected per locus, and
`inheritance` derived from `origin` by UDF.

Version pinning: the source version is supplied at launch time by Airflow (`--version`), not held in
the generated config.
