# Changelog — gnomad_constraint contract MAJOR 1

All notable changes to the `gnomad_constraint` data contract, lineage `1.x`, will be documented in this
file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this contract
adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-09-01

### Added

- Initial contract. The `normalized_gnomad_constraint` dataset family, narrowed to MAJOR 1, is
  published to table `gnomad_constraint_v1`, one row per transcript, from the gnomAD release named by
  the `--version` launch argument.
- Implemented against gnomAD **v2.1.1** — the legacy exome LoF/constraint metrics file
  (`gnomad.v2.1.1.lof_metrics.by_gene.txt.bgz`). gnomAD's current recommendation is v4.1.1's LOEUF
  threshold, but v4.1.1's constraint file (`gnomad.v4.1.1.constraint_metrics.tsv.bgz`) uses a
  different, nested/array-valued schema (per-ancestry array columns, `lof.pLI` instead of a flat
  `pLI`, ...) than this normalizer parses. Moving to v4.1.1 is tracked as a follow-up MAJOR, not this
  one.
- Locus/identity columns: `chromosome`, `start`, `end`, `symbol` (gene), `transcript`, `transcript_type`,
  `gene_id`, `gene_type`, `transcript_level`, `cds_length`, `num_coding_exons`, `gene_length`,
  `brain_expression`.
- Missense constraint: `obs_mis`, `exp_mis`, `oe_mis` (+ `_lower`/`_upper` CI), `mu_mis`,
  `possible_mis`, `mis_z`, and the PolyPhen-restricted `*_pphen` variants.
- Synonymous constraint: `obs_syn`, `exp_syn`, `oe_syn` (+ `_lower`/`_upper` CI), `mu_syn`,
  `possible_syn`, `syn_z`.
- LoF constraint: `obs_lof`, `exp_lof`, `oe_lof` (+ `_lower`/`_upper` CI and its `_rank`/`_bin`/`_bin_6`
  deciles), `mu_lof`, `possible_lof`, `lof_z`, `pLI`, `pNull`, `pRec`, `constraint_flag`.
- Allele frequency / homozygote summary: `n_sites`, `classic_caf` (+ per-population breakdown `afr`,
  `amr`, `asj`, `eas`, `fin`, `nfe`, `oth`, `sas`), `max_af`, `no_lofs`, `obs_het_lof`, `obs_hom_lof`,
  `defined`, `p` (+ per-population breakdown), `exp_hom_lof`.
- ExAC comparison columns: `exac_pLI`, `exac_obs_lof`, `exac_exp_lof`, `exac_oe_lof`.
- Every numeric column is explicitly cast (`castInt`/`castLong`/`castFloat`/`castDouble`) — the raw
  TSV carries no schema of its own.

### Removed

- Not contract-managed prior to this MAJOR: `enriched.Genes` still reads the pre-contract
  `normalized_gnomad_constraint_v2_1_1` table (kept as a frozen legacy input — see the comment in
  `EtlConfiguration.scala` — until `Genes` is migrated to read this branch-qualified contract table).
