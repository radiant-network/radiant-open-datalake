adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-08-06

### Added

- Initial contract. The `normalized_1000_genomes` dataset family, narrowed to MAJOR 1, is published to
  table `1000_genomes_v1`, one row per locus, from the versioned 1000 Genomes Project phase 3 sites VCF
  release named by the `--version` launch argument.
- Locus columns `chromosome`, `start`, `end`, `name`, `reference`, `alternate`.
- Allele-count columns from the VCF INFO block: `ac`, `af`, `an`, `dp`.
- Super-population allele frequencies: `afr_af`, `eur_af`, `sas_af`, `amr_af`, `eas_af`.
