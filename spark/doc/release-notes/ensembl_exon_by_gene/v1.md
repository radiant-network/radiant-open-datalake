## [1.0] - 2026-09-25

### Added

- Initial contract. The `normalized_ensembl_exon_by_gene` dataset family, narrowed to MAJOR 1, is published to table
  `ensembl_exon_by_gene_v1` from the Ensembl GRCh38 GFF3 of the release named by the `--version` launch argument
  (the Ensembl release number, e.g. `114`, which is also the published branch).
- Ensembl is a manual source: the download DAG is triggered with `version=<release>` and fetches
  `https://ftp.ensembl.org/pub/release-<release>/gff3/homo_sapiens/Homo_sapiens.GRCh38.<release>.gff3.gz`
  into the versioned raw prefix. The same file feeds the four Ensembl contracts (`ensembl_gene`,
  `ensembl_transcript`, `ensembl_exon`, `ensembl_exon_by_gene`), launched together by the `ensembl` command.
- Coordinates: `start` is shifted back to 1-based (Glow reports it 0-based), `seqId` is renamed
  `chromosome` (Ensembl naming, no `chr` prefix), and `length` is the feature size in bases,
  `end - start + 1` (both ends inclusive).
- Columns: `gene_id`, `exon_id`, `chromosome`, `start`, `end`, `transcript_ids`, `version` (int), `type`, `strand`, `name`, `constitutive`, `ensembl_end_phase`, `ensembl_phase`, `length`.
- Built from the `ensembl_exon_v1` rows grouped on `(gene_id, exon_id)`: `transcript_ids` is the set of
  transcripts the exon belongs to, every other column is an exon attribute, identical across the group and
  taken with `any_value`. The per-transcript columns of `ensembl_exon_v1` (canonical / MANE flags, `rank`,
  `transcript_support_level`, `tags`) differ across the group and are not carried.
