## [1.0] - 2026-08-13

### Added

- Initial contract. The `normalized_omim` dataset family, narrowed to MAJOR 1, is published to table
  `omim_v1` from the OMIM **genemap2.txt** gene map of the release named by the `--version` launch
  argument (a user-supplied label — OMIM exposes no discoverable version).
- OMIM is a credentialed manual source: the download DAG injects the per-account download key into the
  task at launch (never handled by Airflow) and lands `genemap2.txt` in the versioned raw prefix; the
  job reads it through `RawInput.readVersioned`, substituting `{{VERSION}}`.
- Positional columns of the gene map are named to the platform gene-set schema: `chromosome`, `start`,
  `end`, `cypto_location`, `computed_cypto_location`, `omim_gene_id`, `symbols` (split on `", "`),
  `name`, `approved_symbol`, `entrez_gene_id`, `ensembl_gene_id`, `documentation`.
- The `Phenotypes` field is split on `";"` and exploded to one row per phenotype; each phenotype string
  is parsed (`OmimPhenotype.parse_pheno`) into a `struct<name, omim_id, inheritance, inheritance_code>`,
  mapping the inheritance text to its short code (e.g. `Autosomal recessive` → `AR`). Gene rows with no
  phenotype are preserved with a null `phenotype`.
