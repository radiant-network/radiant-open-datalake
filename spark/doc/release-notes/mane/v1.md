All notable changes to the `mane` data contract, lineage `1.x`, will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this contract
adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-11-05

### Added

- Initial contract. The `normalized_mane` dataset family, narrowed to MAJOR 1, is published to table `mane_v1`
  from the NCBI [MANE](https://www.ncbi.nlm.nih.gov/refseq/MANE/) summary file of the release named by the
  `--version` launch argument (the MANE release, e.g. `1.4`, which is also the published branch).
- MANE is a manual source: the download DAG is triggered with `version=<release>` and fetches
  `https://ftp.ncbi.nlm.nih.gov/refseq/MANE/MANE_human/release_<release>/MANE.GRCh38.v<release>.summary.txt.gz`
  into the versioned raw prefix. Each MANE release is built on one Ensembl release (1.4 on 114, see the
  release's `README_versions.txt`): load the one that matches the published `ensembl_*` tables.
- Columns: `ncbi_gene_id` (int, `GeneID:` prefix removed), `ensembl_gene_id`, `ensembl_gene_version` (int),
  `hgnc_id`, `symbol`, `name`, `refseq_transcript_id`, `refseq_transcript_accession`,
  `refseq_transcript_version` (int), `refseq_protein_id`, `ensembl_transcript_id`,
  `ensembl_transcript_version` (int), `ensembl_protein_id`, `mane_status`, `chromosome_accession`, `start`
  (long), `end` (long), `strand`.
- The Ensembl gene and transcript ids are split into an unversioned id and an int version, so they join
  `ensembl_gene_v1` and `ensembl_transcript_v1` as published. The RefSeq transcript id is split the same way
  (`refseq_transcript_accession`, `refseq_transcript_version`) and also kept whole in `refseq_transcript_id`
  (`NM_000607.4`), as cited in a report. The protein ids keep their version.
- `mane_status` keeps the file's values, `MANE Select` and `MANE Plus Clinical`. Both kinds of rows are kept.
- `chromosome_accession` is the RefSeq accession of the chromosome (`NC_000019.10`); `chromosome_accession`,
  `start`, `end` and `strand` are the file's `GRCh38_chr`, `chr_start`, `chr_end` and `chr_strand` unchanged.
