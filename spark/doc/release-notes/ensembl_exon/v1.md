# Changelog — ensembl_exon contract MAJOR 1

All notable changes to the `ensembl_exon` data contract, lineage `1.x`, will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this contract
adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-09-25

### Added

- Initial contract. The `normalized_ensembl_exon` dataset family, narrowed to MAJOR 1, is published to table
  `ensembl_exon_v1` from the Ensembl GRCh38 GFF3 of the release named by the `--version` launch argument
  (the Ensembl release number, e.g. `114`, which is also the published branch).
- Ensembl is a manual source: the download DAG is triggered with `version=<release>` and fetches
  `https://ftp.ensembl.org/pub/release-<release>/gff3/homo_sapiens/Homo_sapiens.GRCh38.<release>.gff3.gz`
  into the versioned raw prefix. The same file feeds the four Ensembl contracts (`ensembl_gene`,
  `ensembl_transcript`, `ensembl_exon`, `ensembl_exon_by_gene`), launched together by the `ensembl` command.
- Coordinates: `start` is shifted back to 1-based (Glow reports it 0-based), `seqId` is renamed
  `chromosome` (Ensembl naming, no `chr` prefix), and `length` is the feature size in bases,
  `end - start + 1` (both ends inclusive).
- The comma-separated `tag` attribute is split into the `tags` array.
- Columns: `chromosome`, `start`, `end`, `exon_id`, `gene_id`, `transcript_id`, `version` (int), `is_mane_select`, `is_canonical`, `is_mane_plus_clinical`, `type`, `strand`, `name`, `constitutive`, `ensembl_end_phase`, `ensembl_phase`, `rank`, `transcript_support_level`, `tags`, `length`.
- `transcript_id` is the first `Parent` with its `transcript:` prefix removed; the exon is inner-joined to its
  transcript, which supplies `gene_id`, the canonical / MANE flags, `transcript_support_level` and `tags`
  (same derivation as `ensembl_transcript_v1`). Ensembl exon rows carry none of these themselves.
- Only attributes Ensembl sets on exon rows are published. The gene / region attributes (`alias`,
  `description`, `external_name`, `logic_name`) and the GFF `phase` are never set on an exon, so they are
  not columns of this table.
