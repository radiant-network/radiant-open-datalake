## [1.0] - 2026-08-10

### Added

- Initial contract. The `normalized_topmed_bravo` dataset family, narrowed to MAJOR 1, is published to
  table `topmed_bravo_v1` from the TOPMed BRAVO (freeze 8, hg38) allele-frequency VCFs. BRAVO serves the
  callset as one signed VCF per chromosome (`chr1`–`chr22`, `chrX`); the raw glob
  (`bravo-dbsnp-*.vcf.gz`) unions them into one table, one row per variant.
- Locus columns `chromosome`, `start`, `end`, `name`, `reference`, `alternate`.
- Allele counts `ac`, `af`, `an`. `an` is read from `INFO_AN` on freeze 8 and recovered as
  `round(AC / AF)` on freeze 10, which no longer ships it.
- Genotype counts `homozygotes` and `heterozygotes`, taken from the first element of the `INFO_HOM` /
  `INFO_HET` arrays.
- `qual` (the VCF QUAL) and `qual_filter`, a collapsed view of the FILTER column: `PASS` when the only
  filter is `PASS`, `PASS+FAIL` when `PASS` co-occurs with others, `FAIL` otherwise.
