All notable changes to the `ddd` data contract, lineage `1.x`, will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this contract
adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-08-12

### Added

- Initial contract. The `normalized_ddd` dataset family, narrowed to MAJOR 1, is published to table
  `ddd_v1` from the EBI Gene2Phenotype **DDG2P** panel (`DDG2P.csv.gz`) of the release named by the
  `--version` launch argument (a date-stamped `YYYY_MM_DD` G2P directory).
- The download DAG discovers the latest G2P release directory and lands `DDG2P.csv.gz` in the versioned
  raw prefix; the job reads it through `RawInput.readVersioned`, substituting `{{VERSION}}`.
- Columns renamed from the DDG2P header to the platform gene-set schema: `gene symbol` → `symbol`,
  `gene mim` → `omim_gene_id`, `disease name` → `disease_name`, `disease mim` → `disease_omim_id`,
  `confidence` → `confidence_category`, `variant consequence` → `mutation_consequence`, `hgnc id` →
  `hgnc_id`, plus `panel`.
- `variant types` and `phenotypes` split on `"; "` into arrays (`variant_consequence`, `phenotypes`).
