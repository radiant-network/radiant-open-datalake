## 1.0 — initial contract

First declared MAJOR. Table shape is defined by
[`DBSNP.scala`](../../../src/main/scala/org/radiant/opendatalake/normalized/DBSNP.scala), which is the
schema source of truth for this lineage:

- `chromosome`, `start`, `end`, `name`, `reference`, `alternate`, `original_contig_name`
- Only primary assembly contigs are kept (`contigName LIKE 'NC_%'`); the numeric accession is mapped
  to `X` (23), `Y` (24) and `M` (12920), other values are the accession number as a string.
- `alternateAlleles` is exploded, so one row per alternate allele.

Version pinning: the source version is supplied at launch time by Airflow (`--version`), not held in
the generated config.
