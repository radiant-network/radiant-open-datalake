# Changelog — dbsnp contract MAJOR 1

All notable changes to the `dbsnp` data contract, lineage `1.x`, will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/), and this contract
adheres to the lineage rule of [SJRA-1546]: MINOR is bumped in place for an additive change carried by
schema evolution, a breaking change is a new MAJOR with its own changelog file.

## [1.0] - 2026-07-29

### Added

- Initial contract. The `normalized_dbsnp` dataset family, narrowed to MAJOR 1, is published to
  `opendatalake.reference.dbsnp_v1`, one row per alternate allele, from the versioned dbSNP release named
  by the `--version` launch argument.
- Locus columns `chromosome`, `start`, `end`, `name`, `reference`, `alternate`.
- `original_contig_name`, the source RefSeq accession the row came from.
- `chromosome` derived from the accession number, with `23`, `24` and `12920` mapped to `X`, `Y` and
  `M`; every other accession keeps its number as a string.

### Removed

- Non-primary-assembly contigs are excluded: only `contigName LIKE 'NC_%'` rows are published.
